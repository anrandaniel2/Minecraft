# ci/

`release.keystore` – development signing key generated by the first CI run and
committed so that **every build is signed with the same key**. Android refuses
to install an update whose signature differs from the installed app, so a
stable key is what makes the in-app updater work.

This key is public (anyone with repo access can sign with it). For a real
distribution channel set the repository secrets
`RELEASE_KEYSTORE_BASE64`, `RELEASE_KEYSTORE_USER`, `RELEASE_KEYSTORE_PASSWORD`;
the workflow prefers them automatically. Users who installed a dev-signed build
must uninstall once when switching keys.

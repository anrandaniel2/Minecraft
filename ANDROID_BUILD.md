### How to Get Real APK (GitHub UI, not via Sandbox)

Due to E2B sandbox network restrictions:
- Only `github.com` and `api.github.com` allowed via proxy
- Blob storage `*.blob.core.windows.net` for artifacts and `release-assets.githubusercontent.com` for release assets are **blocked** (EOF)
- `gh run download` and `gh release download` fail with EOF
- Token expires after ~15-20m of polling, causing 401 Bad credentials

**Workaround for User**:
1. Go to https://github.com/anrandaniel2/Minecraft/actions/workflows/build-android-final.yml
2. Click latest successful run (e.g., 35542309074)
3. Download artifact `Minecraft-arm64-final` from UI (browser, not sandbox)
4. Or go to https://github.com/anrandaniel2/Minecraft/releases
5. Download APK from release `android-arm64-final-2` or `android-arm64-7`, etc.

### How to Build Locally (Outside Sandbox)

```bash
# Outside sandbox (full internet)
git clone https://github.com/anrandaniel2/Minecraft.git -b arena/01a0c03a-minecraft
cd Minecraft
# Install Godot 4.4.1 Mono from https://godotengine.org/download
# Install Android SDK 34
# Create debug keystore
keytool -genkey -v -keystore ~/.android/debug.keystore -storepass android -alias androiddebugkey -keypass android -keyalg RSA -keysize 2048 -validity 10000 -dname "CN=Android Debug,O=Android,C=US"
# Import and export
godot --headless --import
dotnet build Minecraft.csproj --configuration ExportRelease
godot --headless --export-release "Android" builds/Minecraft-26.3-Android-arm64.apk
# Verify arm64 only
unzip -l builds/Minecraft-26.3-Android-arm64.apk | grep lib/
```
